# Köhnə xidmət səhifələri (arxiv)

Əvvəlki xidmətlər (rəqəmsal marketinq, SMM, dizayn, foto-video, brendinq, kopirayterlik, web-mobile-dev) üçün səhifə şablonu. Saytda görünmür, kod silinməyib.

- Səhifə: `archive/services-legacy/page.tsx` (`app/[locale]/services/[slug]/page.tsx` idi)
- Məlumat: `lib/data/services.data.json`, mətnlər `messages/*.json` → `services`
- Bölmə komponentləri `components/sections/*` yerində qalır.
- Köhnə linklər `next.config.mjs` içində yeni səhifələrə yönləndirilir.

İndiki xidmət səhifələri: `app/[locale]/services/[slug]/page.tsx` (5 xidmət, mətnlər `site.servicePage`).
