# Web & Mobile Dev Hero Image

## Tələb olunan şəkil

Hero bölməsində göstəriləcək vebsayt nümunəsi üçün jpg şəkli lazımdır.

### Şəkil parametrləri:
- **Fayl adı**: `web-mobile-dev-preview.jpg`
- **Yer**: `cradex-agency/public/images/`
- **Format**: JPG
- **Tövsiyə olunan ölçü**: 1200x750px (16:10 aspect ratio)
- **Maksimum ölçü**: 500KB (sürətli yükləmə üçün)

### Şəklin təsviri:
Vebsayt və ya mobil tətbiq interfeysi görünüşü olan screenshot. Təmiz və professional görünüşlü olmalıdır.

### İstifadə yeri:
- `components/sections/WebMobileDevHero.tsx` komponentində
- Web-mobile-dev xidməti səhifəsində (browser frame içində)

### Qeyd:
Şəkil yoxdursa, Next.js build zamanı xəta verəcək. Şəkli əlavə etdikdən sonra:
1. `npm run build` əmrini işə salın
2. Vercel-də avtomatik deploy olacaq
