# Portfolio Şəkilləri

Hər layihə üçün ayrı qovluq yarat:

```
public/images/portfolio/
└── layihe-adi/
    ├── cover.webp     ← əsas şəkil (kart üzərində görünür)
    ├── 1.webp         ← qalereya şəkilləri
    ├── 2.webp
    └── 3.webp
```

Şəkil formatları: WebP (tövsiyə), JPG, PNG
Ölçü: cover üçün 800×600px, qalereya üçün 1200×800px
